HUONG DAN CHAY - NHOM4 (JAVA WEB JSP/SERVLET)

1. Giai nen project.
2. Mo Eclipse -> File -> Import -> Existing Projects into Workspace.
3. Chon thu muc Nhom4 (khong chon thu muc java-nang-cao-main).
4. Dung Apache Tomcat 9.x (project dung javax.servlet, phu hop Tomcat 9; khong dung Tomcat 10 neu chua doi javax sang jakarta).
5. Neu Eclipse bao loi servlet: chuot phai project -> Properties -> Targeted Runtimes -> tick Tomcat 9; hoac Add Library -> Server Runtime.
6. Run As -> Run on Server.
7. Mo:
   http://localhost:8080/Nhom4/tcController
